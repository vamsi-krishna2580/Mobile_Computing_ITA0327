ITA03 - Mobile Computing Laboratory Manual
Python Programming Experiments (Experiments 16-21)

Included programs:
16. Free-Space Path Loss and Received Power
17. Frequency (Co-channel) Reuse: Cluster Size, Capacity and S/I
18. Call Blocking Probability Using the Erlang B Formula
19. Handoff Simulation with Hysteresis
20. Code Division Multiple Access (CDMA): Spreading and Despreading
21. Effect of the OFDMA Downlink Scheduler on User Throughput and Fairness

Requirements:
- Python 3.9+
- NumPy (used by Experiments 16, 19, 20 and 21)

Install NumPy:
    python -m pip install numpy

Run any program:
    python Experiment_16_FSPL_Received_Power.py

Notes:
- Experiment 17 uses Python's built-in math module.
- Experiment 18 uses only Python's standard library.
- The scripts transcribe the Python code supplied in Part B of the uploaded lab manual.
- The manual mentions Matplotlib for graphs, but the code listings for these six experiments
  do not include Matplotlib plotting statements. The provided scripts therefore reproduce
  the listed code and console calculations.
