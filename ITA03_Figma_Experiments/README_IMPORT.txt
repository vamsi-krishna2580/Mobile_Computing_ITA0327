ITA03 Mobile Computing — 15 SVG designs

Import into Figma in Chrome:
1. Extract this ZIP.
2. In your open Figma Design file, switch to the Design tab.
3. Drag one or more .svg files from Windows File Explorer onto the Figma canvas, OR use File > Place image and select an SVG if available.
4. Wait for import. Each SVG is vector artwork. Right-click and choose Ungroup / enter the group to edit individual elements where supported.
5. Repeat for the remaining experiments.

Important:
- These are editable vector diagrams and screen mockups, not native Figma prototype flows.
- To meet the manual's interactive requirements, connect frames/screens using Figma's Prototype tab. Static infographic and flowchart experiments need no complex interactions.
- The mobile UI experiment files contain all five screen mockups in one wide frame. For screen-by-screen prototype navigation, duplicate or separate the screen groups in Figma.
- Keep the SVG files at their original aspect ratio.
